# EMA 小助理（創業管理分析師 300 題線上練習）

專為準備 **EMA 創業管理分析師證照** 的同學打造的免登入線上刷題網頁，完整收錄 EMA 題庫 300 題（111.08 更新版）。

## 線上使用
- 網址：https://liu-shane.github.io/ema-assistant/

## 功能特色
1. **免帳號登入**：開啟網頁即可立即開始練習，紀錄自動保存於本機瀏覽器（`localStorage`）。
2. **牛刀小試**：
   - 每次從 300 題中隨機抽出 10 題單選題（每題 10 分，總分 100 分）。
   - 每題題目結尾標示 `(出自EMA題庫第X題)`，方便對照題庫複習。
   - 交卷後立即主動告知分數、完整解答，並獨立整理「寫錯的題目與正確解答」。
   - 測驗結果底部提供「重新測試」與「離開」功能。
3. **歷史紀錄**：
   - 每次測驗送出皆自動保存成績、作答時間、答對/答錯數與完整題目明細。
   - 隨時點開任意一筆歷史紀錄複習當次錯題與正確答案。
